# ytDesign

Een YouTube-interface voor de TV: een design plus een Firefox-extensie die dat design over youtube.com legt.
Bedoeld voor een mini-pc aan de TV, bediend met airmouse, toetsenbord of D-pad, samen met uBlock Origin.

- [`DESIGN.md`](DESIGN.md) en de `*.dc.html`-bestanden: het design (schermen, kleuren, navigatie).
- [`extension/`](extension/README.md): de Firefox-extensie, met uitleg over ontwikkelen, ondertekenen en
  installeren op de TV-pc.

Het lettertype Montserrat valt onder de SIL Open Font License (`extension/static/fonts/OFL.txt`).
